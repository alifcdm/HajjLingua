## 4. Key Functional Pillars
- **Placement Assessment:** Adaptive level diagnostic test with auto-recommendation.
- **Micro-Learning Units:** Bite-sized interactive lessons covering Alphabets, Vocabulary, Grammar, Dialogues, and Business Scenarios.
- **Pronunciation Engine:** Web Speech API TTS (Arabic, Japanese, Korean, English, Indonesian).
- **Certification Authority:** Digital certificate generation upon 80%+ passing score in final level exams.
